**Nota: este es contenido de demostración generado con fines ilustrativos para el diseño del sitio. No representa una investigación real.**

Este proyecto conceptual explora el uso de residuos agrícolas comunes en la región —como rastrojo de maíz o cáscara de nuez— como insumo para paneles y bloques de construcción de bajo impacto ambiental, en comparación con materiales convencionales de alto consumo energético como el concreto.

El planteamiento de demostración describe un proceso de prensado y compactación con aglutinantes naturales, evaluando de forma hipotética propiedades como resistencia estructural y aislamiento térmico.

Como hallazgo de demostración, se plantea que estos materiales podrían ser viables para construcción no estructural (muros divisorios, aislamiento) más que para elementos que requieren alta carga estructural.
