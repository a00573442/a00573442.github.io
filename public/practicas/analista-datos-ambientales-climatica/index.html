Analista de Datos Ambientales (oferta de demostración)

2 August 2026

Nota: esta es una oferta de práctica de demostración generada con fines ilustrativos para el diseño del sitio. No representa una vacante real.

Descripción: Apoyar en el procesamiento y visualización de datos ambientales (calidad del aire, consumo energético, emisiones) para clientes de distintos sectores.

Requisitos:

  • Estudiante de últimos semestres de Ingeniería en Desarrollo Sustentable, Ciencia de Datos o afín
  • Conocimientos básicos de Excel; se valora Python o Power BI
  • Capacidad de trabajo remoto autónomo

Actividades:

  • Limpieza y organización de bases de datos ambientales
  • Creación de dashboards y reportes visuales
  • Apoyo en el análisis de tendencias de emisiones

Beneficios:

  • Beca de apoyo económico
  • Modalidad 100% remota
  • Horario flexible compatible con clases

Fecha límite para aplicar: Contenido de demostración, sin fecha real.
